# Guia para votar · 2º turno 2026

Guia simples para o 2º turno das eleições de 25 de outubro de 2026: horário, local de votação, documentos e regras para o dia.

Site: https://site-eleicoes-2026.netlify.app/

## Arquivos

- `conteudo.md`: todo o texto do site, com negritos, links e a lista de fontes.
- `index.html`: o site publicado, feito a partir do `conteudo.md`.
- `preview.jpg`: a imagem que aparece quando o link é compartilhado.

## Fontes

Todas as informações vêm do Tribunal Superior Eleitoral (TSE) e de órgãos oficiais. A lista completa, com links, está no fim do `conteudo.md` e do site.

Guia independente, sem vínculo com a Justiça Eleitoral, feito por mim - [Julia](https://www.instagram.com/juliavillela/).
